# 简易现金流计算-测试版

一个只在本机保存数据的 Android 现金流预测工具。维护账户真实余额、周期款项、预算和未来临时收支，即可查看未来余额变化。

## 功能

- 多账户余额：人民币、美元与数字货币分开显示
- 固定收入、支出、转账与分期付款
- 每周、每月、每季度、每年计划
- 周期预算和未来临时收支
- 30、90、365 天余额预测与可查看数值的走势图
- JSON 完整备份与恢复

## 隐私

所有数据仅保存在设备本地。本仓库不包含任何账户余额、备份、APK 或测试数据库。

## 构建

需要 JDK 17 和 Android SDK。用 Android Studio 打开项目后构建 `debug` 版本即可。
