# 未来路线图

## 产品主张

理财不是为了制造焦虑或追逐数字，而是为了扩大人生的选择权，让人更自由地安排时间、工作和生活。

应用首先帮助普通人看清现金流，再逐步建立关于超前消费、本金、复利、风险和长期主义的基本观念。所有内容只做财务通识，不推荐具体股票、基金、贷款或数字货币。

## 1.0：现金流核心

- 极简、定制和完整模式不再隐藏工资、房租、预算、分期及临时收支等核心功能。
- 默认虚构示例只保留工资和房租。
- 分期采用简单方式：填写实际总还款金额、总期数和剩余期数，自动计算每期金额。
- 账户间转账属于真实余额操作，不作为固定计划；同币种转账不改变总余额。
- 设置只保留预测周期、预算起始日、首页币种、账户显示和本地数据管理。

## 1.1：交互优化与第一批财务观念

- 账户名称和真实余额原地修改，不再保留用途单一的编辑按钮。
- 转账入口放入账户卡，自动确定转出账户，增加余额确认与撤销。
- 固定款项不再提供“一次”；单次未来款项统一使用未来临时收支。
- 计划卡显示下次发生日期；分期显示剩余期数和剩余总额。
- 第一批提示覆盖分期总成本、现金为负与应急资金、转账不改变总资产，并允许统一关闭。

后续版本继续扩充可以关闭的小贴士和知识卡片，优先讲清：

- 超前消费：月供较低不等于总成本较低，消费决定会占用未来现金流。
- 本金：先保护承担生活责任的本金，再考虑收益。
- 复利：时间会放大储蓄和投资，也会放大高息债务。
- 风险：价格波动、永久损失、流动性不足和过度集中是不同风险。
- 现金流：资产很多不等于随时有钱支付账单，流动性本身具有价值。
- 应急金：用于抵御意外，不应用高波动资产替代。
- 借贷：同时观察总还款额、手续费和实际年化成本。
- 会计常识：转账不是收入或支出，余额校准也不是收入或支出。
- 自由：储蓄率和可持续现金流最终服务于个人选择权，而不是攀比。

提示采用场景化方式：添加分期时解释总成本，现金可能为负时提示时间差与应急金，预算调整时解释预算和真实余额的区别。避免随机弹窗、说教、焦虑文案和营销式首页。

名人语录只收录可以核实原始出处的短句。每条必须标注人物、来源和年份，并明确区分原话、中文翻译和根据其思想所作的概括；不得收录网络伪语录。巴菲特、芒格等人的思想用于帮助理解本金、安全边际、能力圈、复利、长期主义和反向思考，而不是为任何投资产品背书。

## 1.2：品牌与简易版说明

- 软件名称改为“啥时候有钱”。
- 设置页明确标注简易版边界、开发者、Codex 协助开发、GitHub 与 Blog。
- 理财统计模块尚未加入；存款、基金等未来现金变化暂用“未来临时收支”表达。

## 1.5：自动入账与交互收尾

- 固定收入、固定支出和分期到期后自动更新对应账户真实余额，每期只处理一次。
- 分期同步减少剩余期数与剩余总额，全部完成后停止扣款。
- 新建计划不追溯修改过去的真实余额；旧数据升级时也不补扣历史款项。
- 未来临时收支继续只影响预测，不自动改变真实余额。
- 压缩新增、编辑页面，保持取消和保存按钮可见；修正账户窄屏金额框和首页未来事项时间线。
- 新用户默认提供 PayPal 和数字货币账户，仍可在设置中隐藏。

## 2.0：可选理财与借贷模块

不重新引入复杂使用模式，在设置中按需启用：

- 定期存款的本金、利率、期限、到期本息和现金流日期。
- 贷款总成本、等额本息、等额本金、固定手续费和实际年化成本。
- 基金的持仓成本、手动当前价值、定投和赎回计划；不默认预测收益。
- 复利与定期投入情景计算。
- 应急金目标、储蓄目标和偿债计划。
- 通胀后的实际购买力。

所有复杂计算都必须同时展示假设、公式含义和总现金流影响。

## 2.1：完整理财工具

- 集中提供全部计算器和系统化知识内容。
- 根据完全保存在本机的数据给出规则型风险提示。
- 提示只解释风险和备选行动，不预测市场、不承诺收益、不替用户作投资决定。

## 内容原则

1. 先讲观念，再给公式。
2. 先看最坏情况，再看可能收益。
3. 用总成本和现金流说话，不用低月供制造轻松感。
4. 所有金额计算使用整数最小货币单位。
5. 所有个人数据只保存在用户设备本地。
