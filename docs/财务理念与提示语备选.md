# 《啥时候有钱》财务理念与提示语备选

用途：保存未来版本可用于首页现金预警、财务理念、基础会计知识和理财知识模块的候选文案。

## 首页现金为负提示语

以下 7 句可随机使用：

1. 现金如同氧气，拥有时容易忽视，缺少时只会想到它。
2. 无法预知明天，就要为明天做好准备。
3. 先留有余地，才能从容选择。
4. 安全边际，是自由选择的起点。
5. 先保证走完全程，才有机会赢得比赛。
6. 避免陷入困境，比走出困境更容易。
7. 留住现金，也是在留住选择。

## 使用规则

- 仅在预测出现负余额时显示。
- 每次产生一轮新的负数预警时选择一句；同一轮预警期间保持不变，不因刷新或重新打开首页而跳动。
- 必须同时保留首次为负日期、预计缺口和行动提醒；提示语不能代替关键数据。
- 首页不显示作者，避免将改写内容误认为逐字引语。
- 设置页或未来“财务理念”页面可注明：“部分提示语根据公开财务理念改写。”
- 不把提示语写成训斥、恐吓或营销文案；目标是帮助用户恢复选择空间。

## 来源与性质

- 第 1、2 句根据沃伦·巴菲特关于现金、未来不确定性与准备的论述改写：
  - https://www.berkshirehathaway.com/letters/2014ltr.pdf
- 第 5 句根据巴菲特在 2010 年股东信中引用的赛车原则改写：
  - https://www.berkshirehathaway.com/letters/2010ltr.pdf
- 第 6 句根据查理·芒格常用的逆向思考理念改写：
  - https://www.poorcharliesalmanack.com/seeking_wisdom.php
- 第 3、4、7 句为本项目原创提示语。

## 未来知识模块候选主题

- 现金流：账面有资产，不等于随时有现金可用。
- 安全边际：为意外支出和收入延迟保留缓冲。
- 超前消费：今天的消费会减少未来的选择。
- 本金：本金损失后，需要更高收益率才能恢复。
- 单利与复利：时间既能放大收益，也能放大债务成本。
- 借贷成本：利率之外，还要看到手续费、期限和现金流压力。
- 风险：先考虑能否承受损失，再考虑可能获得多少。
- 资产与负债：能带来现金流的资产，与持续消耗现金的负担应分开理解。
- 收入、支出与转账：转账不改变总资产，支出才会减少资产。
- 预算：预算不是惩罚，而是提前决定把钱留给什么。
- 应急资金：它购买的不是收益，而是时间与选择。
- 财务自由：核心不是拥有最多，而是不被下一笔账单支配。

## 内容边界

- 先讲普通人日常能用的概念，再提供计算工具。
- 明确区分知识、测算与投资建议；不承诺收益，不推荐具体证券。
- 引用人物原话前必须核对可靠来源；无法确认时标为“理念改写”，不冒充原话。
- 简易版不主动增加复杂理财入口；相关内容留给未来定制版或完整模式。
